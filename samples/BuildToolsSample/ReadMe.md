# BuildToolsSample

This retained sample records an earlier mobile build setup. Its project files and legacy configuration are historical and are not the onboarding path for new applications.

For an existing .NET MAUI or Uno Platform solution, follow the [current AppSettings walkthrough](../../docs/config/appsettings/index.md). It includes package placement, exact project keys, `buildtools.json`, `appsettings.json`, generated C# usage, and the differences between released v2.0.245 and forthcoming v3 source. This documentation refresh does not port or revalidate the historical sample.
